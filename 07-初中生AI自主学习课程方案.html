课程方案 · CURRICULUM DESIGN

用 AI Agent 学学习

面向初中生 · 16 周 · 每周 90 分钟 · 一门关于「怎么学」的方法论课

学段：初一至初二 班额：≤ 16 人 形式：每周一次线下 + 日常在家使用 Agent

这门课不教学生怎么写网页、怎么做 PPT、怎么让 AI 替他们写作业。这门课教学生一件事 —— 当他们遇到一个不懂的知识点，怎么调动 AI Agent 自己把它啃下来。网页和记忆卡片只是「啃下来的证据」，不是学习本身。

01为什么需要这门课

初中生已经在大量使用 AI 工具完成作业、写读后感、做小报。但绝大多数学生的使用方式停留在「问答案」—— AI 给一段，他们就抄一段。这种用法既没学到东西，也让大脑越来越懒。

真正有价值的用法是另一个方向：把 AI Agent 当成陪练，学生自己定目标、自己诊断卡点、自己费曼检验。Agent 不是答案机器，而是「永远有耐心、能换角度讲、能追问」的学习伙伴。

这门课的目标，是让学生在 16 周后，独立完成一次「从零学到懂」。拿一道数学题、一个科学概念、一篇英语阅读中的难点，交给 Agent，按照自己设计的学习流程走一遍，最终输出一份能给别人看的笔记网页。

课程定位 · 一句话：这门课培养的是「会用 AI 的人」，不是「被 AI 喂养的人」。前者是主人，后者是宠物。

02课程核心原则（4 条）

原则 1 · 学生是主体，Agent 是陪练

所有学习决策由学生做出：选什么主题、卡在哪、用什么角度切入、何时算通过。Agent 只在被请求时介入，不主动给答案。

原则 2 · 卡点是信号，不是失败

卡住意味着碰到了真不懂的地方。学生必须 停下来诊断——是公式不懂、意义不懂、还是迁移不懂——再决定下一步。硬撑过去等于没学。

原则 3 · 讲得出来才算懂

每个知识点最后都要过「费曼三判据」：能用一句话定义、能给一个反例、能给同桌讲一遍。任何一条不过，回去重学。

原则 4 · 沉淀比进度重要

一周啃一个真问题，比一周刷十个浅问题更有价值。课堂节奏慢一些没关系，沉淀写下来才说明真懂。

0316 周整体节奏

学期按四个阶段推进。阶段之间有明确的「能力跃迁点」，教师据此评估学生是否可以进入下一阶段。前两个阶段因新增工作空间与开场白教学，由原来的各 4 周调整为各 5 周；后两个阶段压缩为各 3 周。

阶段一 · 与 Agent 建立工作关系（第 1–5 周）

学生第一次系统接触 Agent。三件事按顺序发生：① 理解 AI 陪练与 AI 代写的本质区别（第 1 周）；② 搭建「一工作空间 · 多学科对话」的基础设施，按档案 + 进度表组织自己的学习（第 2 周，详见附录 A）；③ 用学科开场白模板真正启动第一次学习对话，跑通从「打开软件」到「让 Agent 给我讲一个真卡点」的完整流程（第 3 周，详见附录 B）；④ 学习提示词三件套与三种角度重讲（第 4–5 周）。

阶段二 · 学会自助学习流程（第 6–10 周）

把用户已经验证过的 35 分钟自助学习流程（读教材 → 自助讲解 → 卡点诊断 → 费曼验证 → 沉淀）迁移到学生身上。学生开始在数学 / 物理 / 英语等学科的真实卡点上跑这个流程，并在第 9 周做一次阶段评估，第 10 周开始接触笔记网页。

阶段三 · 沉淀与表达（第 11–13 周）

学生把每周啃下来的东西整理成「笔记网页」，并在网页里加记忆卡片（闪卡）。网页是沉淀的形式，不是目的。这一阶段的评估重点是：网页里有没有真正体现卡点诊断和费曼验证的过程。第 13 周末做阶段评估，决定学生能否进入冲刺阶段。

阶段四 · 独立完成一个学习项目（第 14–16 周）

学生自选一个真实想学的主题（不限于课本），用 3 周时间走完全流程，最终产出一个能给别人看的「学习作品集」—— 一个网页 + 一组记忆卡片 + 一段讲给同桌的视频。第 16 周举办学习成果发布会。

关于「不教网页」的说明

第 9 周开始学生接触网页工具，但教师只在「必要工具」层面教学 —— 怎么写 Markdown、怎么部署一个静态页面。不教前端框架、不教 JavaScript、不追求美观。如果学生想做得更花哨，鼓励他们用 Agent 帮自己生成代码，但最终内容必须是自己写的沉淀。

04每周 90 分钟的标准流程

每周一次线下课是 90 分钟。这 90 分钟不是「教师讲课 + 学生听」，而是「学生上周在家自学成果的复盘 + 本周新流程的演练」。流程固定，方便学生形成节奏感。

1
10 分钟 · 全员
上周沉淀分享 3 名学生（轮流）上台讲 3 分钟：「上周我啃下来了什么 / 我卡在哪 / 我怎么破的」。其他同学用一句话在卡片上写下「我从他这里学到的 / 我有疑问的」。讲完后卡片交本人，作为下周复盘的素材。
2
5 分钟 · 全员
本周学习主题发布 教师发布本周任务卡（见第 6 节），学生领取，写下自己的初步计划。
3
25 分钟 · 独立
现场演练：跑一次 35 分钟流程的浓缩版 学生现场打开自己的 Agent，按本周任务的卡点，用 25 分钟跑一个浓缩版自学流程。教师巡场观察，但不主动介入。学生卡住超过 5 分钟可以在卡片上写下「我的卡点」，课间找教师。
4
25 分钟 · 2 人小组
同桌费曼 学生两两一组，互相讲自己刚才啃下来的东西，用费曼三判据检验对方。第 1 分钟：讲概念。第 2 分钟：让对方给反例。第 3 分钟：让对方用最朴素的话复述。每组互讲 2 轮。
5
15 分钟 · 全员
课堂沉淀 学生当场写下 5 分钟沉淀（用教师给的模板）：本课我懂了 X / 我还卡着 Y / 下周要解决 Z。教师收齐，作为本周评估的依据。
6
10 分钟 · 教师
教师集中反馈 + 下周预告 教师挑 2 个本节课最有代表性的卡点（一个「破了」的、一个「没破」的），全班一起看怎么破。最后发布下周任务卡。
教师角色定位

课堂上的教师不是讲师，是教练。90 分钟里，教师讲话时间控制在 20 分钟以内，剩下 70 分钟都是学生在学、在讲、在卡、在破。任何「教师讲、学生听」超过 5 分钟的环节，都需要重新设计。

05学生在家怎么用 Agent（课后规范）

每周线下课之外，学生至少要花 3 次 × 35 分钟 在家用 Agent 学习。这一节规定在家怎么用。

5.1 每周必走的三段

  1. 啃一个真卡点：从本周课内学习中挑一个真不懂的（不是已经会的），用 35 分钟流程跑通。
  2. 写一份沉淀：5 分钟内写完「本课我懂了 X / 我卡在 Y / 下周要解决 Z」，发到班级共享文档。
  3. 更新笔记网页：把这次啃下来的内容整理成网页的一节，并生成 ≥ 2 张记忆卡片。

5.2 什么时候该找 Agent，什么时候不该

应该找 Agent不应该找 Agent
三种讲法都不通，真的卡死了没自己想过就问 Agent 要答案
想让 Agent 扮演 K12 学生，听自己讲一遍让 Agent 替自己写作业 / 写作文
想要反例或变体题不思考，直接让 Agent 给「答案」
想让 Agent 检查自己写的费曼讲法把 Agent 的话复制粘贴到自己的笔记里
想让 Agent 用代数 / 几何 / 类比三种角度重讲问「这个考不考」「难不难」这种回避问题

5.3 一份「对话审计」习惯

学生每周交一份「对话审计」（200 字以内）：这周我和 Agent 聊了 N 次 / 哪次最有收获 / 哪次我意识到自己其实在偷懒 / 下周我要改什么。这份审计不是给教师打分的，是给学生自己看的 —— 让他意识到自己怎么用 Agent。

06提示词模板（学生可直接套用）

下面 4 个模板是学生在不同场景下直接复制使用的。教师在第 3 周集中教学，之后学生根据自己学科调整。

模板 1 · 让 Agent 用三种角度讲一个概念

你是我的学习陪练，不是老师。

我要学的是：[具体概念，例如「负数的乘法」]

请按下面三种角度依次讲给我：
1. 代数法（用公式、符号、计算）
2. 几何 / 图形法（画图、看形状、看关系）
3. 类比法（用一个我熟悉的场景做翻译）

讲完后，给我一个费曼提问，让我用自己话讲一遍。
不要直接给结论，先等我听完三种讲法。

模板 2 · 让 Agent 给我出反例 / 变体题

我刚学完：[概念]

请做两件事：
1. 给我一个不满足这个概念的例子（反例），并解释为什么它不满足
2. 给我 2 道变体题，比课本例题稍微难一点。我做完后请你判断我的思路对不对

不要给我答案，等我做。

模板 3 · 让 Agent 扮演 K12 学生听我讲

你现在扮演一个初一学生，叫[名字]，对[概念]完全不懂。

我要用我自己话给你讲这个概念。你要：
- 听到不懂的地方就打断我追问
- 听完之后用你（初一学生）的话复述一遍
- 如果我讲错，你要说「我有点没听懂」并指出哪里怪

我讲完，你复述完，我再请你给反馈。

模板 4 · 让 Agent 检查我的沉淀笔记

这是我这周的学习沉淀笔记：

[粘贴自己的笔记]

请你按下面三条检查：
1. 我有没有用自己话定义这个概念？（如果都是抄的，请指出）
2. 我有没有给反例？
3. 我有没有写「我还卡在哪」？

不要美化我的笔记，直接说哪里是空的、哪里是糊弄的。
关于提示词的再强调

这 4 个模板的共同点是：学生先做，Agent 后评。所有让 Agent 「直接给答案」的提示词，教师要在课堂上专门做反面教材讲一次。一旦学生发现哪种提示词是「偷懒模式」，就要从他的习惯里剔除。

07教师评估体系

这门课不评分（不考试），但教师需要判断每个学生是否真的在「用 Agent 学」而不是「让 Agent 替他学」。评估分四块。

7.1 评估维度

维度 A
自主性 · 学生能否独立发现问题、设定目标、诊断卡点，而不是等着教师或 Agent 告诉他下一步做什么。
维度 B
过程感 · 学生笔记里有没有保留「卡点 / 失败 / 换角度」的过程痕迹，还是只写结论。
维度 C
费曼能力 · 学生能不能用朴素的话给别人讲明白，能给反例，能在被追问时不慌乱。
维度 D
Agent 使用健康度 · 学生的对话审计里有没有出现「我意识到自己在偷懒」的反思。

7.2 评估等级（仅用于阶段过渡，不打分数）

等级含义处理
L1 · 起跑 还在「让 Agent 给答案」的惯性里，需要教师持续陪跑 留在当前阶段，多一周专项练习
L2 · 上路 能用三种角度重讲，但费曼讲法还卡顿，反例常想不出 进入下一阶段，但每周配 1 次教师面谈
L3 · 巡航 能独立完成 35 分钟流程，沉淀里有过程感，能给同桌讲明白 正常推进，可以承担同桌费曼的「教」角色
L4 · 领跑 能帮同学改提示词、能拆解同学的卡点，网页作品被同学引用 第 16 周项目可自选主题、独立完成

7.3 阶段评估节点

  • 第 9 周末：阶段一 / 二过渡评估。教师与每个学生 5 分钟面谈，判断能否进入「沉淀与表达」阶段。
  • 第 13 周末：阶段二 / 三过渡评估。教师看每个学生的笔记网页 demo，判断是否进入「独立项目」阶段。
  • 第 16 周末：学期总评。一场 10 分钟的学习发布会，邀请家长和低年级学生旁听。

08第 16 周 · 学习成果发布会

学期最后一周不考试，举办一场「学习成果发布会」。每个学生有 10 分钟，向全班 + 邀请的家长 / 低年级学生讲解自己 4 周冲刺项目的成果。

8.1 学生必须展示的三样东西

1. 笔记网页

  • 一个完整的可访问网址（可以托管在免费静态网站服务上）
  • 网页里能看到至少 4 周的学习沉淀
  • 包含记忆卡片（≥ 10 张）
  • 关键节有「卡点诊断」「费曼检验」的过程痕迹

2. 一段讲解视频（3–5 分钟）

  • 主题自选（项目里啃下来的最深的一个点）
  • 必须包含：一句话定义 + 一个反例 + 给初中生讲一遍
  • 画面里要有 Agent 对话截图（证明用了 Agent，不是嘴说）

3. 一份对话审计

  • 整个 4 周冲刺期与 Agent 的对话数量、关键时刻
  • 不少于 3 次「我意识到自己在偷懒」的反思
  • 不少于 1 次「Agent 给的答案我拒绝了 / 重做了」的记录

4. 自我评估

  • 用 L1–L4 等级给自己定位
  • 写一段话：下学期我想继续深挖什么
  • 这段话不要求好听，要求真实

8.2 发布会的特别环节 · 「你问我答」

发布会最后 5 分钟，台下学生和旁听家长可以自由提问。教师提前给一份「刁钻问题清单」让提问者参考：你这个概念的反例是什么 / 你哪一次最想放弃 / 你的 Agent 给了你几次错误答案。

教师在这一天的角色

教师不是评委，是第一个鼓掌的人。评价由学生互评 + 家长反馈承担。教师的工作是在发布会前一周与每个学生 1v1 过一遍，确认学生能扛住刁钻提问。

09教师备课清单（开课前 2 周）

9.1 教师自己要跑一遍流程

在开课前，教师自己必须先用这套方法论完整啃一个真问题。建议选一个自己也不懂的、跟初中课程相关的主题（如「为什么负负得正」「欧姆定律的几何含义」），跑 3 周，按上面 4 个阶段自己走一遍。这是教师能教这门课的唯一前提。

9.2 准备 3 套工具

  • 课堂沉淀卡：每张印好模板，学生课上 5 分钟填写并上交。
  • 卡点诊断表：5 类卡点（建模 / 意义 / 抽象 / 迁移 / 结构）+ 对应破局法，学生人手一份贴在课本上。
  • 对话审计模板：周记式 200 字模板，引导学生反思而非汇报。

9.3 与家长沟通

开学家长会必须讲清楚三件事：

  1. 这门课不刷题、不考试、不排名。
  2. 学生每周用 Agent 学习的痕迹会出现在班级共享文档里，家长可以看到但不要代替。
  3. 评估维度里有「Agent 使用健康度」，如果发现学生只用 Agent 抄答案，教师会专项介入。

9.4 与学校 / 班主任沟通

  • 说明这门课挤占的是「信息课」或「综合实践」课时，不影响主课成绩。
  • 说明学生产出的网页 / 视频不需要购买任何付费工具（全部用免费静态网站服务 + 免费 Agent）。
  • 说明第 16 周发布会邀请校长 / 教务主任旁听，作为这门课的成果汇报。

10常见担忧与回应

担忧 1 · 学生会不会让 Agent 替自己做所有事？

这是最常见的担心，也是这门课存在的核心理由。如果不在课堂上系统训练「怎么用 Agent」，学生迟早会滑向「让 Agent 替自己写」。本课程的核心评估维度「Agent 使用健康度」专门针对这一点 —— 学生每周必须有一次「我意识到自己在偷懒」的反思。偷懒被发现反而是好事，被发现意味着学生还有自我觉察。

担忧 2 · 学生之间水平差异太大，怎么教？

这门课的天然好处是 Agent 提供个性化陪练。课堂上的 35 分钟流程是统一的，但学生自己选的主题、卡点难度可以完全不同。教师的角色是「卡点诊断」，不是「统一进度」。水平高的学生啃难的主题，水平低的学生啃基础主题，但都要走完同一套流程。

担忧 3 · 学生做的网页会不会很丑？

网页丑没关系，过程痕迹清晰才是核心。本课程鼓励学生用纯 Markdown + 简单模板做网页。如果学生花超过 20% 的时间在调样式，教师要提醒他回到内容。如果学生真的想做好看，鼓励他用 Agent 生成 CSS 框架，但样式工作不能挤占内容沉淀的时间。

担忧 4 · 家长会不会觉得「不学正经东西」？

第 16 周发布会是最好的回应。当家长看到自己孩子用 10 分钟讲明白一个概念，并展示过去 4 周的真实学习过程（含卡点、含失败、含重学），会意识到这门课的价值。开学家长会要明确告知评估方式，让家长预期对齐。

11这门课对教师的长期影响

这门课不只是给学生的方法论课，也是教师的「再学一次」机会。当教师自己跑过 3 周流程之后，会有三个转变：

  1. 不再相信「我讲一遍学生就懂」—— 你会看到学生真实的卡点有多深。
  2. 不再相信「刷题就能掌握」—— 你会看到沉淀 5 分钟比刷 10 道题更值。
  3. 不再把 AI 当威胁—— 你会把它当成放大自己教学能力的杠杆。

这门课成功的标志，不是学生网页做得多漂亮，而是学期结束后，学生在家遇到不会的题，第一反应是打开 Agent 自己啃，而不是问家长 / 抄同学 / 等老师讲。

最后一件事。这门课可以迭代。学期中你会发现某些环节不工作 —— 学生不爱写对话审计、提示词模板用不上、卡点诊断表变成摆设。把这些反馈记下来，下学期调整。这门课本身也应当用「自助学习系统」的逻辑去迭代 —— 卡点就是信号，换角度重讲，不要硬撑。

附录 AAgent 工作空间与对话结构

学生在用 Agent 学习时面临的第一道坎不是「写提示词」，而是「打开软件不知道该怎么组织对话」。如果不规定结构，学生容易出现两种问题：① 所有学科混在一个对话里，Agent 不知道当前在学什么、上下文被噪声淹没；② 每次开新对话都从零开始，Agent 不记得学生卡过哪里、破过哪里。

本课程规定每个学生必须建立「一工作空间 · 多学科对话」的结构。这条规范从第 2 周开始执行，是学生使用 Agent 的基础设施。

A.1 工作空间的总结构

一个工作空间 = 一个学生的一学期全部学习。每个工作空间下，按学科拆分成独立对话。每个学科下，再按「主题」拆分成更小的对话。

为什么要拆对话而不是拆工作空间

常见错误是每个学科建一个工作空间。坏处是：① 学生要在多个工作空间之间来回切，节奏被打断；② 跨学科时（比如数学物理结合的应用题）没有统一上下文；③ 学习者档案和进度表要重复维护。一个工作空间下多个学科对话，是「既有隔离又有共享」的最优解。

A.2 三类对话的分工

对话类型作用何时新建何时关闭
学科对话
（如「函数与代数」）		 按主题长期跟进，包含多次 35 分钟流程的积累 第一次碰到该主题时 该主题整个学期结束、且沉淀已写进网页后归档

A.3 学习者档案 · 模板（每个工作空间必备）

这份档案是 AI 了解你的「身份证」。学生开每个新学科对话时，第一步是让 AI 先读档案。下面是档案模板，教师第 1 周发给学生填写：

# 学习者档案

## 我是谁
- 名字：[填写]
- 年级：[填写]
- 哪几科学得最吃力：[填写]

## 我用 Agent 的目的
不是让 Agent 替我写作业。
是让 Agent 当陪练，帮我把不懂的东西啃下来。

## 我的学习节奏
- 每周在家用 Agent 学习 [3] 次，每次 [35] 分钟
- 每周课后写一份沉淀，5 分钟内写完
- 我知道自己卡点是正常的，不硬撑

## 我对 Agent 的三条要求
1. 不要直接给答案，先问我「你想从哪里切入」
2. 我卡住时，换三种角度（代数 / 几何 / 类比）重讲
3. 我讲完之后，给一个费曼提问，不要夸我

## 我这学期的目标
[用自己的话写一段，2-3 句即可]

A.4 学科进度表 · 模板

每个学科目录下配一份进度表，每周日更新一次。它有两个作用：① 学生自己看「我走到哪了」；② 学生在学科对话里问「我上次卡在哪」时，AI 能秒回。

第 2 周教学重点

第 2 周的 90 分钟课堂整个用来做这件事：全班在教师带领下，集体创建工作空间、填写档案、按学科开对话。不允许学生回家再做 —— 因为回家做会卡在「软件操作」上，挫败感会盖过方法论学习。课堂做、当堂过、当场演示一次「打开对话 → 让 AI 读档案 → 开始学」完整流程。

附录 B单学科对话的开场白模板

档案和进度表到位之后，学生面对的具体问题是：「我打开一个新学科对话，第一句话该说什么？」下面按学科给出 5 个可直接复制的开场白模板。学生第一次开某学科对话时，整段复制粘贴即可，第二次开始才允许改写。

开场白的四件套结构

所有学科开场白都遵循同一结构：① 你是谁（读档案）→ ② 我现在卡在哪（读进度）→ ③ 这次我想做什么 → ④ 我对你的要求。学生学会这一结构后，能自己套到任何新学科。

B.6 开场白的「修改权限」规则

第一次开某学科对话时，学生整段复制模板使用，不允许改写。从第二次起，学生可以根据自己的实际卡点改写「我卡住的地方」和「我已经懂了」两段，但「我对你的要求」四点和收尾的「请开始」句式必须保留。

为什么保留这四点？因为它们是这门课的方法论核心 —— 学生改写「卡在哪」是合理的（个性化），但改写「我对你的要求」就意味着学生在逃避被陪练（懒化）。

第 3 周教学重点

第 3 周的 90 分钟课堂做两件事：① 全班用 25 分钟，按自己主科学科把 5 个模板里的某一个跑通 —— 不要求全跑完，但要求看到 AI 第一次回应；② 接下来 25 分钟，两人一组互换学科，让对方帮你诊断开场白有没有写漏（例如档案忘了让 AI 读、要求里忘了「不要夸我」）。最后 25 分钟全班展示一次「完美开场白」长什么样。

本课程方案由用户已有的「Daily Learning · 自我学习教学设计」迁移而来，原始方法论见 `06-自我学习教学设计.md`。

核心迁移逻辑：把面向成年学习者（计算机专业毕业 7 年的成人）的 35 分钟自学流程，改造为面向初中生的 16 周课程。三个主要改动：① 增加线下课堂作为「陪跑 + 反馈」机制，弥补初中生自控力不足；② 把网页 / 闪卡作为沉淀形式引入，给初中生明确的产出感；③ 增加「对话审计」环节，专门针对初中生「让 Agent 替自己学」的高发风险。
