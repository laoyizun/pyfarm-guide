🎮 游戏进度 · 仙人掌规则

📌 仙人掌的特殊之处

  • 每株仙人掌有个"尺寸"，范围 0~9，用 measure() 读自己，measure(East) 读右邻居。
  • 判断"排好"：北和东的邻居都 ≥ 自己，南和西的邻居都 ≤ 自己。
  • 排好前是棕色，排好后变绿。
  • 收一株排好且连成片的，整片一起被收，产量是 n²（n 是连片大小），不排好几乎白种。

📖 知识卡 · 4 张

① 嵌套 for：行列都要扫

扫一个二维网格，需要 for 套 for——外层管行，内层管列。

size = get_world_size()
for y in range(size):           # 每一行
    for x in range(size):       # 每一列
        # 当前在 (x, y)
        move(East)
    move(North)

② 状态标记：changed = True/False

排序要做"反复扫直到稳定"。"稳定"是看不出来的——用一个布尔变量记"这一轮有没有交换"。

changed = True
while changed:                 # 还要继续
    changed = False            # 默认这一轮不动
    for y in range(size):
        for x in range(size - 1):
            if measure() > measure(East):
                swap(East)
                changed = True # 发生了交换

③ swap(方向)：和邻居交换

和 move 不同，swap 是"我和邻居换位"——是这一关的"魔法指令"。

if measure() > measure(East):
    swap(East)    # 我比右边大，右边比我小 → 交换
# 交换后 measure() 现在是原来右边的值

④ 反向：用一个函数处理方向

蛇形扫描需要"这一行从左到右、下一行从右到左"。用 reverse() 把 East 变 West：

def reverse(d):
    if d == East:  return West
    if d == West:  return East
    if d == North: return South
    return North

dir = East
# ... 扫完一行后
dir = reverse(dir)    # 东变西，西变东

🔧 常见报错 · 卡住了先看这里

measure() 在最后一列报 None → 边界越界。最后一列没有东邻居，需要判断 x != size - 1 再 measure。

无人机越扫越乱，永远不停 → changed 没在合适的时候重置，或者 while 条件写成了 while True。

死循环：无人机原地不动 → 扫完一行忘了 move(North)，或者 move(East) 漏了。

整片没变绿，产量很低 → 横向是从大到小，纵向是从小到大——两个方向要选对大小比较。
