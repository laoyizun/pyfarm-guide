① 算术运算符：+ - * / % // **

算术运算符把两个数算成一个新的数。左边和右边都是"数"，结果是"数"。

符号叫什么怎么用举例注意
+加 两个数相加5 + 3 → 8 也能拼字符串
-减 左边减右边5 - 3 → 2 写 - 是减法
*乘 两个数相乘5 * 3 → 15 写 x 是乘不是变量 x
/除 左边除以右边5 / 3 → 1.6667 永远返回小数
//整除 除完只留整数部分5 // 3 → 1 要整数就用它
%取余 除不尽剩下的部分5 % 3 → 2 本关最常用
**幂（次方） 左边 的 右次方2 ** 3 → 8 读作"2 的 3 次方" 
# 农场里最常用的两种：

x % 2 == 0        # x 是偶数 → 棋盘格判断
crops[x % 3]      # 按 3 列轮作 → 列表轮作

% 取余是这一关最常用的——判断奇偶、棋盘格、轮作都靠它。/ 永远返回浮点数，要整数得用 //。

② 比较运算符：== != > < >= <=

比较运算符把两个值比一下，结果不是数字，而是 True（真）或 False（假）。

符号叫什么怎么用举例注意
==等于 两边一样吗5 == 5 → True 两个等号
!=不等于 两边不一样吗5 != 3 → True 感叹号表示"非"
>大于 左边比右边大吗5 > 3 → True > 朝左开口
<小于 左边比右边小吗3 < 5 → True < 朝右开口
>=大于等于 左边不小于右边吗5 >= 5 → True 包含"等于"
<=小于等于 左边不大于右边吗3 <= 3 → True 包含"等于" 
# 一个 = 是赋值，两个 == 才是比较：

x = 5            # 把 5 放进变量 x
if x == 5:    # 判断 x 是不是 5
    quick_print("库存正好 5")

最常见的报错：if x = 5:（只写一个等号）→ 报 SyntaxError。记住：左边是变量、右边是值，用两个等号。

③ 逻辑运算符：and / or / not

逻辑运算符把多个 True/False 组合成一个，用来表达"两个条件都要满足"这类复合要求。

符号叫什么怎么用举例农场里的用法
and并且 两边都是 True 才 True True and False → False 有水 and 缺水才浇
or或者 只要一边是 True 就 True True or False → True 是树 or 是灌木都收
not不是 / 取反 True 变 False，反之亦然 not True → False not can_harvest() 没熟 
# 复合条件：两个条件都满足才浇水
if num_items(Items.Water) > 0 and get_water() < 0.5:
    use_item(Items.Water)

# 取反：还没成熟才补种
if not can_harvest():
    plant(Entities.Bush)

写复杂条件时宁可多打括号：if (x % 2 == 0) and (y % 2 == 0): 比 if x % 2 == 0 and y % 2 == 0: 清楚得多。

④ 优先级：拿不准就加括号

一行里有多个运算符时，按优先级决定先算哪个。顺序如下（从高到低）：

优先级运算符说明
1（最高）( )括号：括号里的先算
2**幂
3* / // %乘除、取余
4+ -加减
5== != > < >= <=比较
6（最低）not → and → or逻辑
 
2 + 3 * 4           # 14，先乘后加
(2 + 3) * 4         # 20，括号优先
# 在农场里这么写：if (x % 2 == 0) and (y % 2 == 0):

⑤ get_water() 是 float，不是 int

这一关特别容易踩的坑：get_water() 返回 0.0 ~ 1.0 的小数（水分比例），不是 0~100 的整数。

get_water()          # 比如 0.75（75% 水分）
num_items(Items.Hay) # 整数，比如 250

想判断"水够不够"写 get_water() < 0.75，别写成 get_water() < 75。

订单 2

智能浇水：缺水才浇、没水不浇

📋 客户要求 在订单 1 的棋盘格田上继续。每一格：先收 → 再种 → 缺水才浇。缺水（get_water() < 0.5）且水库存够（num_items(Items.Water) >= 1）才调 use_item(Items.Water)。水不够或水分已经够都不浇。
必须用 and 必须用 < / >= 必须用 num_items(Items.Water) 必须用 get_water()

把"判断条件"先写在纸上：什么情况下才浇水？两个条件都满足才浇——这叫"复合条件"，是这一关的关键。

🔧 常见报错 · 卡住了先看这里

树和树挤在一起，长不大 → 棋盘格条件错了。x % 2 == 0 and y % 2 == 0 是黑格，x % 2 == 1 and y % 2 == 1 也是黑格——这两种情况都得种树。

胡萝卜种下去直接死了 → 没翻土，胡萝卜需要 Grounds.Soil，不能直接种在草地上。

游戏报错 NameError: Water → 新版本里可能没有 Items.Water，或者名字变了，去游戏内文档查。

if 永远为真 / 永远为假 → 拿浮点数和整数比。比如 get_water() < 75 永远为真（因为 0.0~1.0 永远小于 75），要写 0.75。
