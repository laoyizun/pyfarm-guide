📖 知识卡 · 4 张

① 列表：用 [] 装一组数据

列表就像一组编号的小格子，按下标（从 0 开始）取东西。

crops = [Entities.Carrot, Entities.Pumpkin, Entities.Sunflower]
petals = [5, 8, 3, 12, 7]
empty = []          # 空列表

② 索引：crops[0] 是第一个

下标从 0 开始，crops[0] 是第一个，crops[1] 是第二个。不要写 crops[1] 当成第二个，错的话报 IndexError。

crops = ["胡萝卜", "南瓜", "向日葵"]
print(crops[0])     # 胡萝卜（第一个）
print(crops[1])     # 南瓜（第二个）
print(crops[2])     # 向日葵（第三个）
print(crops[3])     # 报错：IndexError: list index out of range

③ append / len：往里加、问多长

petals = []
petals.append(5)        # 列表变成 [5]
petals.append(8)        # 列表变成 [5, 8]
petals.append(3)        # 列表变成 [5, 8, 3]
print(len(petals))      # 3，列表长度
print(max(petals))      # 8，最大值
print(sum(petals))      # 16，总和

④ for x in list：遍历列表

这是把"列表学完"的关键用法：遍历就是把列表里每个东西挨个拿出来一次。

crops = ["胡萝卜", "南瓜", "向日葵"]
for c in crops:
    print(c)
# 输出三行：胡萝卜 / 南瓜 / 向日葵

这一关的精髓是组合：用 len() 取列表长度，用 % 取余，用 [] 取元素——一行代码替代一堆 if。

三色轮作田（增删皆宜）

订单 2

烂格记账：列表第一次当账本

📋 客户要求 解锁南瓜（Pumpkin）后，全田种南瓜。南瓜长大时会随机"枯死"，要凑成"巨大南瓜"必须没有烂格。任务：扫一遍全田，把烂格的坐标（x, y）append 进列表，再用 for 循环 for x, y in bad: 解包，走回烂格补种，直到列表清空，最后整片一起收。
必须用 append 必须用列表 [x, y] 存坐标 必须用 for x, y in bad: 解包 必须用 while len(bad) > 0

解包：for x, y in bad: 会把 [2, 1] 拆成 x = 2, y = 1 两个变量——这是 L4 函数的"参数解包"前身，先在这里熟悉手感。

🔧 常见报错 · 卡住了先看这里

IndexError: list index out of range → 下标越界。3 个元素的列表最大下标是 2，写 3 就报错。

只种了第 0 列的作物 → 列表写成了 (...)（元组）而不是 [...]（列表）。游戏里元组不可改。

append 不生效 → 写成 crops = crops.append(x)，这是错的。append 不会返回新列表，它直接改原来的。

为什么 crops[1] 是"南瓜"不是"胡萝卜" → 下标从 0 开始。0 才是第一个。
