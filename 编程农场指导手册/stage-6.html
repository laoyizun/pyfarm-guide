📖 知识卡 · 5 张

① 方向也能放进列表

把四个方向装进一个列表，用下标表示"朝向"：

dirs = [North, East, South, West]   # 顺序：北、东、南、西
# dirs[0] 是北，dirs[1] 是东，dirs[2] 是南，dirs[3] 是西

② 取模转向：左转右转不会越界

把"朝向"当成下标，加 1 是右转，减 1 是左转。再用 % 4 防止下标越界。

facing = 0            # 朝北（dirs[0]）
facing = (facing + 1) % 4     # 右转一次 → 朝东
facing = (facing - 1) % 4     # 左转一次 → 又回北
# % 4 保证下标永远在 0~3 之间

③ can_move：探墙但不真正走

can_move(方向) 返回 True/False，失败的 move() 也要花 1 tick——但 can_move 不花，所以常用 can_move 先试。

if can_move(East):
    move(East)        # 走得通才走
else:
    pass              # 走不通换别的

④ 坐标解包：measure() 返回两个值

在迷宫里站在宝箱上调用 measure()，返回一对坐标——下一颗苹果在哪。

tx, ty = measure()    # 解包：返回 (tx, ty) 一次拆成两个变量
print(tx, ty)

⑤ 终止条件：走到哪算哪

没有固定循环次数——用 while + 条件判断"什么时候该停"。

while get_entity_type() != Entities.Treasure:
    # 还没到宝箱，继续走
    pass
harvest()              # 到了！收宝箱

🚜 农场订单 · 闯关任务

订单 1

左手扶墙：解迷宫

📋 客户要求 生成一个新迷宫，无脑"左手扶墙"走到宝箱。具体规则：能左转就左转，否则直走，都不行就右转。站上宝箱时 harvest()。
用方向列表 用 % 4 防越界 用 can_move 探墙 while 条件 + 终止判断

这是 1.0+ 版的"入门解法"——复用迷宫会出环，新迷宫无环。先生成新迷宫再走。

订单 2

恐龙帽：吃苹果追尾巴

📋 客户要求 戴恐龙帽，循环：站在苹果上 measure() 拿到下一个苹果坐标 → 走过去 → 撞到自己尾巴就停。最后摘帽，骨头数 = n²。
change_hat() 坐标解包 用 quick_print 判断 None 终止

⚠️ 重要：measure() 必须在还站在苹果上时调用。吃掉苹果后 measure() 就不是这个意思了。
先用 set_world_size(5) 缩小农场练习，别上来就 32×32。

🔧 常见报错 · 卡住了先看这里

迷宫跑一圈回到原点 → 复用了同一个迷宫（有环）。每次重新生成新迷宫，harvest() 旧的再种新的。

IndexError 越界 → facing - 1 在 facing=0 时是 -1，忘了 % 4。

measure() 返回 None → 没苹果了，这是正常的结束条件，要写 if nxt == None: break。

恐龙帽戴不上 → 仙人掌数量不够（需要先囤一定数量）。

循环里 print 卡住 → 改用 quick_print()，print 每次花 1 秒。
