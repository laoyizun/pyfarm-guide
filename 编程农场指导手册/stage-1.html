API 名字以游戏内文档为准 不同版本的 API 名字有差异。比如新版本里 trade() 已被移除，浇水改成 use_item(Items.Water)；Grounds.Turf 改成 Grounds.Grassland。如果你照老脚本跑报错，先看游戏里能不能点出这个 API。

📖 知识卡 · 4 张

① while True：让无人机不停干活

这一关只需要两个动作：循环和判断。while True 的意思是"永远循环下去"，是自动化脚本的标准开头。

while True:
    # 下面这些动作每轮都执行一遍
    if can_harvest():
        harvest()
    move(East)

⚠️ 注意缩进：第二行前面的空格不能漏，Python 是用缩进判断"哪些代码属于循环内"的。

② if / else：让程序会"思考"

判断会返回 True 或 False，如果是 True 就跑 if 下面的代码，否则跳过（或跑 else 下面的）。

if can_harvest():       # 能收吗？
    harvest()            # 能就收
else:
    pass                 # 不能就算了（pass 是"什么都不做"）

③ 变量存坐标：get_pos_x() / get_pos_y()

想知道无人机站在哪一行哪一列，用 get_pos_x()（列号，0 开始）和 get_pos_y()（行号）。返回值是整数。

x = get_pos_x()
y = get_pos_y()
# x 和 y 就是变量，里面存着当前位置的数字

④ 走遍全田：到行末就换行

田是一格一格的，无人机走到最右边怎么办？答案是判断 get_pos_x() == 0 时向下走一格（注意：游戏里走到行末会自动绕回 0）。

move(East)
if get_pos_x() == 0:        # 走到行末自动绕回
    move(North)              # 往下一行走

🔧 常见报错 · 卡住了先看这里

IndentationError: unexpected indent → 缩进对不齐。第 2 行前面必须比第 1 行多 4 个空格。复制代码后最容易出这个错。

SyntaxError: expected ':' → if 或 while 后面忘了冒号。

无人机在原地抖动 → can_harvest() 写成了 can_harvest（漏了括号）。Python 看到没括号的"函数名"会当变量，不会执行。

只走一格就停 → while 没写 True，或者根本没写 while。
